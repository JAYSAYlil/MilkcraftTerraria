# 七种永久坐骑（0.2.13）

把召唤物放入原版坐骑栏，使用快捷骑乘键（默认 R）召唤或解除，也可以直接使用召唤物。骑乘期间可以使用武器。

## 亡灵军马与圣天狗

|坐骑|定位|固定配方|制作站|
|---|---|---|---|
|亡灵军马|机械Boss阶段；快速陆行，120帧有限飞行储备|源质锭8＋恐惧之魂5＋丝绸10|秘银/山铜砧|
|圣天狗|击败石巨人后；持续飞行、松键悬停|叹息羊毛8＋甲虫外壳5＋飞翔之魂10|秘银/山铜砧|

召唤物可反复使用，不消耗已制作的装备。两条配方保留原生微光分解。已有角色无需重开世界，可按配方制作。

## 能力

白虎与九尾狐连续双击同一个左右方向键发动冲刺，冷却1.5秒。白虎基础冲刺伤害45，无敌帧0.3秒；九尾狐基础伤害125，无敌帧0.5秒。伤害受怪物防御和原生伤害计算影响；同一次冲刺对同一敌人只打一次。已有更长无敌帧不会被冲刺缩短。两只均不能飞行。

犀牛骑乘时加8防御；移动碰撞基础伤害70–90，随速度提高，对同一敌人间隔0.5秒。静止不反复撞击，不能飞行。碰撞按坐骑身体范围处理并检查遮挡。

烈焰战马在坚实地面移动时留下火焰，火焰持续3秒，触碰敌人造成基础30伤害并施加3秒狱炎，同一片火焰对同一敌人间隔0.5秒。火焰不伤害骑手、不烧毁物块；粒子与照明为橙红金色。跳跃和停步不持续生成火焰。不能飞行。

白色独角兽持续飞行，可悬停并使用上下键升降；保持原版无翅膀的白色独角兽造型，脚下有白色粒子、角和眼睛有局部发光。
