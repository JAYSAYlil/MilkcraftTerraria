# 当前全部模组物品配方（0.2.13）

每次制作数量如下，全部固定成功。新矿只生成于新世界；已有世界可通过Boss掉落取得升级材料。

三王的真理武器材料及炼金核心全部必掉；石巨人按战士→射手→法师循环，同轮次破碎武器材料与药水核心各1，普通直接掉落，专家／大师进入原版宝藏袋。三种T4材料的职业分配是本模组适配。

炼金台消耗酒精1激活一次并保存；重摆需重新激活。附魔台零普通合成配方，右键选背包物品与附魔，使用原版钱币付费，计价参照哥布林重铸，实际费用随所选物品显示；保留原版前缀，一件物品仅一个奶块附魔。重复选择同种附魔不收费。

T3／T4仍需要对应许可穿戴；现在许可必须收集三职业材料，因此需要三种配对核心；机械三王全击败的称号规则保留。
