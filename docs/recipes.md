# 当前全部模组物品配方（0.3.3.5）

表中列出每次制作的产量、材料、工作站和世界条件。新矿在新世界生成，也可通过Boss掉落取得矿物材料。

Boss普通模式在本体掉落固定材料，专家／大师材料在对应宝藏袋中；纪念章1/10、面具1/7、大师遗物100%。怨灵武士／丛林领主／女妖每只掉落黑铁矿石120＋粉钻8＋对应凭证1；丛林领主另掉皮革20＋丛林孢子5，女妖另掉粗布20＋坠落之星5。三只T3奶块Boss各掉真理武器材料1、核心2及附魔之心1；城堡核心同时掉落三职业T4材料。世纪之花掉落白色九尾狐，月亮领主掉落断掉的铁剑。七种Boss召唤物成功召唤消耗一件。

炼金台消耗1酒精激活，拆除重摆后需要重新激活。附魔台用于付费特殊附魔：右键选择背包物品及附魔类型，每件物品保留一种特殊附魔，可与已有重铸词条叠加。费用为当前物品价值的三分之一，折扣卡先八折，最低1铜；重复选择现有附魔不收费。

T3／T4装备需要对应许可；T3许可由三枚暮色Boss凭证制作，T4许可由城堡核心通关凭证制作。
