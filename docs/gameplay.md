# 工作站、进度与附魔（0.2.13）

本页汇总已实装的制作链与附魔机制。逐项材料与数量以 [全部配方](recipes.md) 为准。

## 升级路线



T1使用原版铁砧／铅砧制作。击败克苏鲁之脑或完整世界吞噬者，每次追加黑铁矿石120、粉钻24；专家和大师从原版宝藏袋领取。奶块熔炉把3矿石熔成1黑铁锭，再把4黑铁锭＋1粉钻制成8魔铁锭，供T2战士制作；射手和法师的皮革、羊毛在纺织台制作。T1/T2武器和护甲均改在原版铁砧／铅砧完成。

机械骷髅王追加真理之剑、水晶颅骨；毁灭者追加真理之弓、异种角质；完整击败双子魔眼追加真理之杖、奥术核心。每种核心可炼制6瓶对应特殊药水，再批量生产T3装备材料。T3武器消耗真理材料，保留已有T2武器。T3/T4护甲、武器和许可在秘银砧／山铜砧制作。

石巨人每次追加一组同职业材料，按战士→射手→法师循环：

|职业|破碎武器材料|药水核心|药水|
|---|---|---|---|
|战士|破碎的剑柄|凋零之泪|魂铸药水|
|射手|破碎的弓弦|恶魔之翼|深渊药水|
|法师|破碎的杖柄|附魔胫骨|黑暗药水|

三次完整击败覆盖三职业，每次固定一件破碎材料＋一件核心。循环进度随世界保存；专家／大师的袋子在掉落时记录职业，留到以后或带去其他世界打开不会改换职业。开袋不推进循环。T4武器消耗破碎材料，保留已有T3武器。

恶魔之翼、附魔胫骨、凋零之泪是奶块原有材料；上述三职业的分配是本模组适配。所有核心均固定掉落，炼金必出，不加入随机失败。

现有新阶许可仍要求三职业材料，所以新取得T3许可需要收集三王的全部核心，T4许可需要石巨人的三组材料。已经解锁的旧角色许可继续保留。

## 工作站怎么用

|站点|用途|
|---|---|
|奶块合成台|制作基础工作站，仍可充当原版工作台|
|蒸馏台|仅制作酒精|
|炼金台|用1酒精永久激活后，制作六种特殊药水|
|附魔台|右键选择奶块武器或副手，添加一种奶块附魔|
|精炼锻造台|仅制作盾牌、箭袋、法典|
|奶块熔炉|仅制作黑铁锭、魔铁锭、源质锭、赤炼锭|
|纺织台|制作皮革和各阶皮料、羊毛|

手持酒精对完整炼金台使用，或拿酒精右键炼金台，消耗1瓶激活整台。激活后的玻璃容器和符纹呈青蓝发光，木质台架保留原材质。激活永久保存；重复操作不扣酒精；拆下重摆恢复未激活。必须站在激活台的制作范围内，未激活台不提供药水配方。六种药水是合成材料，没有饮用Buff。

附魔台的制作增加血肉墙100%掉落的原创材料“附魔之心”；精炼锻造台的制作增加原版工匠作坊。

黑铁矿和粉钻矿仅在新世界自然生成，生成规模参照原版魔矿／猩红矿。旧世界无需重建，仍可通过击败克脑／世吞获得材料。粉钻替代原配方中的任意宝石位。

## 奶块附魔

右键附魔台，选择背包里的奶块剑、弓、杖、盾牌、箭袋或法典，再选择允许的附魔。使用原版钱币付费，费用参照哥布林重铸并随所选物品显示；固定成功。每件只有一种奶块附魔，重新选择会替换旧的；重复选择现有附魔不收费。原版重铸前缀保留。不再消耗粉钻和坠落之星，也不需要单独的暂存物品格。

费用为当前物品价值的三分之一，适用折扣卡时先八折再计算，最低1铜。附魔台不受NPC幸福度影响。支持背包与原版钱币储存支付，余额不足时不改物品。

|---|---|---|
|锋利|剑|该剑伤害＋6%|
|力量|弓／箭袋|远程伤害＋6%|
|魔咒|杖／法典|魔法伤害＋6%|
|暴击|盾／箭袋／法典|对应职业暴击率＋4个百分点|

|隐蔽|弓／杖|持有时仇恨－400、移动速度＋4%|
|盾墙|盾|伤害减免＋4%|

武器加成随当前持有或对应来源攻击生效；副手必须放在功能饰品栏。背包和时装栏不提供副手属性。寒冰、治愈和爆裂配有对应颜色的触发特效；假人、友好目标、PvP不用于刷治疗或连锁爆炸。

附魔名字沿用奶块类型，数值及单人防御／移速收益按泰拉瑞亚适配。已认可的套装奖励、配套被动和武器攻击方式继续保留。

附魔数据支持SaveData/LoadData/Clone/NetSend/NetReceive；工作站操作服务端校验距离、目标背包槽/type/prefix/附魔当前值与成本，网络重复包不双扣。不移动待附魔物进虚拟暂存槽，以避免关闭窗口/断线吞物。显示正常原版物品格，通过现有背包槽选择引用。清晰显示当前所选物品和可选类型，关闭/离开范围立即关闭。爆裂、治愈共用每玩家冷却，不因换杖或多弹越过；爆裂衍生弹不能触发套装/配对额外连锁。
