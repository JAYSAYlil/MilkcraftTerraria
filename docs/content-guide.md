# 奶块 × 泰拉瑞亚内容指南

版本 **0.3.3.5** · 适用 Terraria 1.4.4.9 / tModLoader 1.4.4 stable。

模组包含战士、射手、法师三个职业的T1–T4装备、武器和副手饰品，以及七个Boss、八种坐骑和七种宠物。炼金使用固定配方，装备升级需要材料与对应等级的许可。

共159件模组物品、101条相关配方：100条模组产出与1条皮革补充配方。文末列有全部物品的制作与获取方式。

## 从开荒到终局

| 阶段 | 主要目标 | 升级方式 |
| --- | --- | --- |
| T1：困难模式前 | 选择战士、射手或法师，搭建基础工作站 | 铁／铅、金／铂金、皮革、粗布等原版或加工材料；武器护甲在铁砧／铅砧制作 |
| T2：克脑／世吞之后 | 挑战怨灵武士、丛林领主、女妖 | 获取黑铁矿石和粉钻，在奶块熔炉、纺织台加工职业材料；铁砧／铅砧制作装备 |
| T3：机械三王阶段 | 取得T3许可，挑战黑曜石守卫、斯芬克斯、冰霜女巫 | 三枚暮色凭证制作T3许可；击败至少一位机械Boss后使用。三只T3奶块Boss掉落真理武器材料、药水核心及附魔之心；制作材料包括机械魂和神圣锭 |
| T4：石巨人之后 | 挑战城堡核心，取得T4许可与三职业材料 | 城堡核心一次给齐三职业破碎材料、药水核心和通关凭证；制作并使用T4许可，再加工T4装备材料 |
| 终局：月亮领主之后 | 制作大粥的铁剑 | 月亮领主掉落断掉的铁剑，与四把模组剑在秘银／山铜砧合成 |

T3、T4许可属于角色，使用一次永久解锁对应等级的装备功能；未激活时对应装备属性／使用受限制。已取得的许可换到较早进度世界仍保留，首次使用和制作仍检查当前世界进度。T3称号在当前世界击败黑曜石守卫、斯芬克斯、冰霜女巫三者后解锁，与T3许可分开。

三只T3奶块Boss的召唤条件为困难模式和对应地表群系。T3药水、装备材料和许可的制作要求击败至少一位机械Boss。

### 材料加工路线

| 职业 | T2 | T3 | T4 |
| --- | --- | --- | --- |
| 战士 | 黑铁矿石 → 黑铁锭＋粉钻 → 魔铁锭 | 水晶颅骨 → 圣殿药水 → 源质锭 | 凋零之泪 → 魂铸药水 → 赤炼锭 |
| 射手 | 皮革等 → 狂野兽皮 | 异种角质 → 梦魇药水 → 华丽皮革 | 恶魔之翼 → 深渊药水 → 破魔鞣革 |
| 法师 | 粗布等 → 魔法羊毛 | 奥术核心 → 堕落药水 → 魔纹羊毛 | 附魔胫骨 → 黑暗药水 → 叹息羊毛 |

上表为材料加工路线。六种特殊药水是合成材料，每份核心可制出6瓶对应药水。完整材料与加工数量见[全部配方](recipes.md)。

## 工作站与制作链

| 工作站 | 当前职责 |
| --- | --- |
| 奶块合成台 | 制作基础工作站，并能充当原版工作台 |
| 奶块熔炉 | 制作黑铁锭、魔铁锭、源质锭、赤炼锭 |
| 纺织台 | 制作皮革、粗布及各阶皮料、羊毛 |
| 精炼锻造台 | 制作奶块盾牌、箭袋、法典；配方包含原版工匠作坊 |
| 蒸馏台 | 制作酒精 |
| 炼金台 | 激活后制作六种特殊药水 |
| 附魔台 | 给奶块武器与副手添加付费特殊附魔；制作需要附魔之心 |

T1、T2武器和盔甲在铁砧／铅砧制作，T3、T4武器和盔甲在秘银／山铜砧制作。副手饰品在精炼锻造台制作。

手持酒精对炼金台使用，或拿着酒精右键炼金台，消耗1瓶永久激活整台。容器和符纹出现青蓝发光即表示激活；站在其制作范围内才显示药水配方。重复激活不扣酒精，拆下重摆需要重新激活。

黑铁矿与粉钻矿在新世界自然生成，也可通过怨灵武士、丛林领主、女妖取得黑铁矿石与粉钻。3黑铁矿石熔成1黑铁锭，4黑铁锭＋1粉钻制成8魔铁锭。附魔之心由黑曜石守卫、斯芬克斯、冰霜女巫固定掉落。

## 付费特殊附魔

右键附魔台 → 选择背包内奶块剑、弓、杖、盾、箭袋或法典 → 选择可用附魔并支付原版钱币。固定成功，一件物品只保留一种奶块附魔；重新选择会替换，重复选择已有附魔不收费。盔甲不参与此机制。

特殊附魔可与物品已有的重铸词条叠加。费用为当前物品价值的三分之一，折扣卡先八折，最低1铜；不受NPC幸福度影响。可使用背包和钱币储存付款，余额不足不改变物品。

| 附魔 | 载体 | 当前效果 |
| --- | --- | --- |
| 锋利 | 剑 | 该剑伤害＋6% |
| 力量 | 弓、箭袋 | 对应远程伤害＋6% |
| 魔咒 | 杖、法典 | 对应魔法伤害＋6% |
| 暴击 | 三种副手 | 对应职业暴击＋4个百分点 |
| 挑衅 | 剑 | 持有时仇恨＋400、防御＋4 |
| 隐蔽 | 弓、杖 | 持有时仇恨－400、移速＋4% |
| 盾墙 | 盾 | 伤害减免＋4% |
| 护甲 | 三种副手 | 防御＋4 |
| 抗性 | 三种副手 | 敌对弹幕最终伤害降低6% |
| 寒冰 | 杖 | 有效命中使可受影响的非Boss敌人减速20%，持续2秒 |
| 治愈 | 杖 | 有效命中回血2，每2秒最多一次，受生命汲取额度限制 |
| 爆裂 | 弓、杖 | 对命中点48像素半径内其他敌人造成该命中伤害30%，每0.5秒最多一次 |

爆裂对主目标以外的附近敌人生效，衍生爆炸不触发额外爆炸。治愈与爆裂不对假人、友好目标或PvP触发。冷却按玩家计算。

## 微光、旧世界与联机

有合成配方的盔甲、武器、饰品、工作站、未使用许可、加工材料及合成坐骑支持微光分解。分解材料与数量按游戏的微光规则处理。仅通过采矿或掉落取得、没有制作配方的物品不提供额外分解结果。

分解物品不会复制角色已经使用的永久许可，也不会把附魔、重铸词条或炼金台激活状态变成额外材料。炼金台拆除重摆需要重新激活。

角色已取得的许可、称号与物品在更换世界后保留。Boss通过召唤物挑战。黑铁矿脉、粉钻矿脉及白虎宝箱奖励在新世界生成；已有世界可通过Boss与钓鱼获得对应材料、坐骑。

专家／大师模式中，Boss生命随参与人数增加。目标死亡、断线或变为幽灵后，Boss转向其他有效目标；没有有效目标时退场，不发放击杀奖励。距离过远也会触发离场。专家／大师模式的参战玩家可分别获得宝藏袋。
